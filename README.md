# Kidrove
URL link: https://kidrove-beta.vercel.app/

Kidrove Workshop Landing Page is a full-stack web application built to showcase a children's workshop and provide a seamless registration experience for parents. The project focuses on creating a modern, responsive, and user-friendly interface while integrating backend functionality for handling registrations.

• Developed a responsive single-page application using React, TypeScript, and Tailwind CSS.

• Designed and implemented key sections including Hero, Workshop Details, Learning Outcomes, FAQ, Registration Form, Navbar, and Footer.

• Built reusable and maintainable components with a clean folder structure.

• Centralized workshop content in a dedicated data file, making updates and content management simple and scalable.

• Implemented client-side form validation for name, email, and phone number to improve user experience and prevent invalid submissions.

• Developed a backend API using Node.js and Express.js to process registration requests.

• Created a POST /api/enquiry endpoint to accept and validate registration data.

• Integrated MongoDB using Mongoose to store registration details securely with automatic timestamps.

• Added server-side validation for required fields, email format, and phone number verification.

• Implemented proper error handling and structured API responses using appropriate HTTP status codes.

• Configured environment variables using dotenv and enabled cross-origin requests using CORS.

• Optimized application performance by removing unnecessary dependencies and reducing the JavaScript bundle size from approximately 345 kB to 211 kB.

• Followed modern development practices including component reusability, separation of concerns, and clean code principles.

Tech Stack: React, TypeScript, Tailwind CSS, Vite, Node.js, Express.js, MongoDB, Mongoose, Nodemon, dotenv, and CORS.
